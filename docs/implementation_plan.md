# Implementation Plan

## Feature 1: Answer Questions
Trigger: player starts a level.

The player answers general bio questions.
Correct answers increase score.
Wrong answers decrese health.

## Feature 2: Multiple Levels
Trigger: player completes a level.

The game moves the player to the next level.
Each level has different questions.

## Feature 3: Health and Score
Trigger: player answers a question.

Correct answers give points.
Wrong answers take away health.

## Feature 4: Retry Questions
Trigger: Player misses questions.

Incorrect questions are saved.
The player retries them later.
